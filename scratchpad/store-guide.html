Running the ShopEasy store

Everything needed to manage the shop day to day — where each admin screen lives, what it's for, and the exact steps for the tasks you'll do most often. No technical background required.

Getting started

The store has two sides, both in the same web address — just different pages:

🛍️ The shop front What customers browse and buy from. Open the site's main address — e.g. https://your-store-address/.
🔑 The admin panel Where you manage everything. Add /admin/login to the same address — e.g. https://your-store-address/admin/login.
Your exact web address depends on how the site was deployed (a local test link, or a live domain once launched). Whoever set up the site can give you the current one — the /admin/login part at the end is always the same.

What customers see

Worth knowing the customer side, since it's what your admin changes affect. A visitor can browse freely without an account:

PageWhat it does
HomeFeatured categories, featured products, items on sale, new arrivals.
Category / subcategory pagesProducts filtered by what you've organised them under in the admin panel.
Search & All productsFull catalog with filters (category, price, in-stock, on sale) and sorting.
Product pagePhotos, price, stock status, description, "Add to cart".

Adding an item to the cart, or checking out, requires the customer to log in or create an account first — that's by design, so every order is tied to a real customer record.

At checkout, a customer picks Cash on Delivery or online payment (card / UPI / netbanking via Razorpay), enters a delivery address, and places the order. Both payment types, and every order afterward, are fully visible to you in the admin panel.

Logging in to the admin panel

  1. Go to /admin/login on the store's address.
  2. Enter the admin email and password you were given.
  3. You'll land on the Dashboard — the admin home screen.

Don't have admin credentials yet?

Only someone with command-line access to the server can create the first admin account (it's a one-time setup step, not something done from a web page). Ask whoever deployed the site to create your login, or to reset your password if you're locked out.

Security note: 5 wrong password attempts locks that login for 15 minutes. This applies to admin accounts too — it's a protection against guessing attacks, not a bug.

Where things are

The left-hand sidebar in the admin panel has every section you'll use. Here's what each one is for:

Sidebar itemWhat you'll do there
DashboardAt-a-glance numbers: total orders, pending orders, revenue, low-stock and out-of-stock counts, recent orders, newest customers.
CategoriesTop-level sections of your catalog (e.g. "Electronics", "Fashion"). Create, rename, reorder, upload a category image, or deactivate one.
SubcategoriesSit inside a category (e.g. "Mobiles" inside "Electronics"). Same controls as categories, plus which category each belongs to.
ProductsYour full item catalog: name, price, sale price, description, SKU, stock, and photos. This is where most of your daily work happens.
InventoryA stock-focused view across all products — filter to just what's low or out of stock, and update quantities quickly without opening each product.
OrdersEvery order placed, with filters by status and payment method. Open one to see items, customer, address, payment details, and to move it through its delivery stages.
PaymentsA payment-focused log — useful for reconciling what's been paid, what failed, and why (shows the actual gateway error for failed online payments).
UsersEvery registered customer (and admin). Search, and promote a customer to admin or deactivate an account.
CouponsDiscount codes — percentage or flat amount off, with optional minimum order value, usage limits, and expiry.
ContentEdit the text on your About, Privacy Policy, and Terms pages, plus your public contact email/phone/address — without needing a developer.
SettingsA read-only summary of technical configuration (payment gateway status, storage backend, shipping/tax defaults) — useful when troubleshooting with a developer.

Walkthrough: add a category, subcategory, and product

Products always live inside a category (and usually a subcategory), so set those up first.

1. Create the category

  1. Sidebar → Categories → New category.
  2. Enter a name (e.g. "Electronics") and, optionally, a description and image.
  3. Leave Active checked so it's visible on the shop front, then Save.

2. Create a subcategory inside it

  1. Sidebar → Subcategories → New subcategory.
  2. Pick the parent category from the dropdown, name it (e.g. "Mobiles"), then Save.

3. Add the product

  1. Sidebar → Products → New product.
  2. Choose the category and subcategory, then fill in name, SKU (a unique code — anything you like, as long as it's not reused), price, and stock quantity.
  3. Sale price is optional — set it lower than the regular price to show a "% off" badge; leave it blank otherwise.
  4. Save the product first.
  5. You'll now see an Upload image panel — add one or more photos. The first photo becomes the main image shown on product cards; you can change which one is "main" or delete any of them afterward.
Product photos appear uncropped — the full image always shows, so upload roughly square photos for the cleanest look on cards.

Walkthrough: update stock

  1. Sidebar → Inventory (fastest for bulk checks) or open the product directly under Products.
  2. Use the filter buttons — Low stock / Out of stock — to see what needs restocking.
  3. Edit the quantity in the row and click Save. No page reload needed.

Low stock threshold is the number at which a product starts showing an amber "low stock" warning — set per product when you create or edit it.

Walkthrough: process an order

  1. Sidebar → Orders. Filter by status or payment method, or search by order number / customer name.
  2. Open an order to see the full breakdown: items, customer, shipping address, payment method and status, and a history of every status change.
  3. Move it forward using Update status — the dropdown only shows the statuses that make sense next (e.g. a placed order can go to Confirmed or Processing, not straight to Delivered).
  4. COD only Once a Cash-on-Delivery order is delivered and you've collected the cash, click Mark payment as collected in the Payment section — this is separate from the delivery status, since the two don't always happen at the same moment.
Cancelling an order automatically returns the reserved stock to inventory — you don't need to adjust quantities manually afterward.

Walkthrough: edit About / Privacy / Contact text

  1. Sidebar → Content.
  2. Pick the page or field to change — e.g. "About us", "Support email", "Business address" — and click Edit.
  3. For the long pages (About, Privacy Policy, Terms), type your text and leave a blank line between paragraphs — each one becomes its own paragraph on the live page.
  4. Save changes. The public page updates immediately — no developer, no redeploy.

Walkthrough: create a coupon

  1. Sidebar → Coupons → New coupon.
  2. Set a code customers will type (e.g. WELCOME10), a discount type (percentage or flat amount), and the value.
  3. Optionally set a minimum order value, a maximum discount cap (useful with percentage coupons), and a usage limit.
  4. Save — it's live immediately. Customers enter it at checkout.

Who can do what

RoleCan do
Visitor (not logged in)Browse, search, view products — cannot add to cart or check out.
CustomerCart, checkout, view their own order history and profile. No access to the admin panel at all.
AdminEverything above, plus the full admin panel described in this guide.

An admin can promote any customer to admin (or the reverse) from Users → Edit — useful for handing off management to someone else on your team later.

Troubleshooting

I forgot my admin password

Use "Forgot password?" on the regular login page (not the admin one) if your account has an email set up for reset links, or ask whoever manages the server to reset it directly — it's a one-line command on their end.

"This account does not have admin access"

You're logging into /admin/login with an email that exists but isn't marked as an admin. Ask an existing admin to promote your account under Users → Edit.

A product's image isn't showing

Open the product in Products and check an image has actually been uploaded — new products start with no photo (they show a placeholder). If a photo was uploaded and still isn't showing, tell your developer — it may need a quick server check.

An order is stuck on "pending payment"

Normal if the customer closed the payment window without finishing — the reserved stock is automatically released back to inventory. No action needed unless the customer says they were actually charged, in which case check Payments for that order and contact your developer if the gateway shows a successful charge that isn't reflected.

I locked myself out after too many failed logins

Wait 15 minutes and try again — this is an automatic anti-guessing protection, not something that needs to be manually cleared.
